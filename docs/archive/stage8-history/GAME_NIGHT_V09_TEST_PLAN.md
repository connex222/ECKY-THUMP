# ECKY THUMP v0.9 — At-home playtest plan

## Equipment

- One Windows laptop running the server (or one Render deployment).
- Three to six phones and optionally one TV (a good first playtest is four people).
- For two or three homes, use the same **public HTTPS hosting URL**, not localhost.

## Test runs

1. **Clean / 3 players / Quick:** create room, scan QR, choose avatars, play Card Clash and Quick Wit, finish and replay.
2. **Cheeky / 4–6 players / Full Games Night:** complete the six rounds, test a card swap, play again and check prompt freshness.
3. **Adult / 4–6 adults / Full Games Night:** check adult participation confirmation and content suitability; test report/hide response.
4. **Remote / two locations:** use a TV display per home, then disconnect a phone and reconnect.
5. **Maximum capacity / 12 players:** check readable TV results, reasonable timers, and that nobody receives duplicate cards during a round.

## Questions to ask your friends

- Did you laugh more than you expected? Which particular card/prompt triggered it?
- Which round did you want to play again immediately?
- Which round felt too complicated, too slow, or too similar to another?
- Was the Adult mode *funny*, rather than merely rude?
- Did anybody get bored waiting for typing, votes, or results?
- Was the Last Laugh bonus fair?

## Release gates

- A full 3–12 player game and a second match must complete without a softlock.
- TV and phone views must expose neither private hands nor entry authors before voting ends.
- No unsupported claims that all text is safe or playtest-approved.
- A human reviews the content editorial decisions before declaring any pack sellable.
