# ECKY THUMP v1.1 — The Games Night Flow Update

## How to start

1. Extract the ZIP file into a new folder.
2. Open `ECKEY-THUMP-Game-Night-v1.1-Flow`.
3. On Windows, double-click `START-GAME-WINDOWS.bat`. Node.js 20+ must already be installed.
4. Your computer opens the game. Create a room, select Clean, Cheeky or Adult humour, and choose 2, 4 or 6 rounds.
5. Each friend joins via the room QR code or invite link. You need at least three players.
6. For a TV screen, the host taps **OPEN TV**. You may show the TV view in each household.
7. Press **START THE SHOW** and play the five challenges.

## What's new in v1.1

- Each challenge now explains what to do directly on the phone.
- Gold/Silver voting has a clearer selection tracker.
- After results, each contestant can tap **I'M READY FOR THE NEXT ROUND**.
- The host sees a live ready count, plus the next challenge name, and can advance at any time.
- The TV results view shows how many people are ready and what happens next.
- The championship screen includes the number of rounds, ballots and scored entries, plus up to three top-voted moments.
- Countdown displays account for differences between the server clock and devices' clocks.
- The TV cards reveal in a short staggered animation; reduced-motion preferences are respected.

## Games night recommendation

- Choose **Relaxed** for friends in the same home or 2–3 homes. The host moves to the next challenge when everyone is ready, leaving time for laughter and conversation.
- Choose **Lively** for shorter rounds. Results still advance automatically after the short reveal period, unless the host continues sooner.
- Let one TV play lobby music and sound effects; avoid multiple nearby phones playing the same audio.
- Choose **Full Games Night — 6 rounds** to experience all five challenges.

## Important limitations

- **This is not a public commercial release.** Adult-content safety and broader moderation need further development.
- Rooms are temporary and disappear on a server restart.
- For friends in different houses, the game needs a hosted HTTPS server. A localhost address won't work remotely.
- Automated tests pass, but the new UI should still be checked on a real TV and multiple phone types.
