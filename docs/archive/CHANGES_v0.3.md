# The Nonsense League — v0.3 Chaos UI Update

## Summary
This version keeps the same game rules and games-night scope, but changes the presentation to feel far more chaotic, theatrical and game-show-like.

## Visual changes
- Stronger colour palette with hot pink, gold, cyan and electric violet accents
- More dramatic gradients, glows and layered background atmosphere
- Louder headlines and more expressive section naming
- Sticker-style chips and “games night mayhem” treatment on the landing screen
- More energetic cards, voting panels and scoreboard styling
- Tilted card and candidate layouts for a controlled-chaos feel
- Bolder TV display styling for prompts, result reveals and the leaderboard
- Stronger timer and status states

## Behaviour
- Core gameplay logic unchanged
- Host / guest / TV workflows unchanged
- Existing tests still pass

## Intent
The aim of v0.3 is to move away from a generic polished web app and closer to a loud, slightly unhinged party-show identity suitable for real games nights.
