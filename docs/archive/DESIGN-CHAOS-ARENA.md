# v0.6 Chaos Arena — Art direction and test notes

This is an independent design direction based on visual feedback from the NOGGIN project. It adopts high-production **stylistic principles** (blue-and-gold TV game-show lighting, contestant panels, marquee and high legibility) but uses original artwork and characters. It is not a clone of NOGGIN graphics.

## UI changes
- Full-screen studio with blue/violet lighting and bright golden marquee
- Oversized eccentric championship title, original character line-up: Disco Pigeon, Bent Banana, Angry Toaster and Traffic Cone
- Stage-inspired player cards, scoring, card choices and TV answer reveal
- Glowing buttons and clear controls across phone-only and TV-and-phone experiences
- Four original lightweight SVG character illustrations locally bundled under public/assets/arena/

## Behaviours kept
Private room, 3–12 friends, optional TV in multiple homes, clean/cheeky/adult settings, 2/4/6 round choices, Card Clash and Quick Wit, host controls and scoring. No public matchmaking or payments.

## Testing
Run `npm test`. Browse the landing, join, play, vote and TV views at desktop and phone sizes; validate on real devices before a live party.
