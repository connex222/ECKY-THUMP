# Start ECKEY THUMP v1.0 — Showtime Showdown

1. Extract the ZIP; open the `ECKEY-THUMP-Game-Night-v1.0-Showdown` folder.
2. Double-click `START-GAME-WINDOWS.bat` (Node.js 20+ required).
3. Create a private game; choose humour, rounds and pace.
4. On the lobby TV, click **PLAY LOBBY MUSIC** to hear the lobby loop.
5. Click **ENABLE SHOW SFX** to allow sounds during rounds, votes and results.
6. Share the QR code or room link with 2+ other players and start.

For two or three houses: deploy one server to your Render instance, then have everyone use the same public HTTPS game URL. Never scan a QR code pointing to `localhost` from another device.
