# ECKY THUMP v0.9.2 — Start Here

1. Extract this ZIP file.
2. Double-click `START-GAME-WINDOWS.bat` (Node.js must be installed).
3. Create a room. Choose humour, length and pace using the visible selection tiles.
4. In the lobby, open **TV DISPLAY** and scan the QR code with your phone.
5. Click **PLAY LOBBY MUSIC** on the TV or host device. The other players should keep audio off to avoid several copies at once.
6. Start after at least three players join. Music stops automatically once the match begins.

For players in different houses, the game must be hosted on a publicly accessible HTTPS service. The QR link must point at the publicly hosted address.

The game has not been pushed to GitHub or Render automatically.
