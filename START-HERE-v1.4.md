# Start Here — ECKEY THUMP v1.4

1. Download and extract the ZIP. Open the `ECKEY-THUMP-v1.4` folder.
2. Double-click `START-GAME-WINDOWS.bat` on Windows (Node.js 20.11+), or run `npm start`.
3. Select **HOST A GAME**, enter a nickname, optionally expand **CHOOSE YOUR CHARACTER**, and select humour, game length and pace.
4. Create the room. Share the room link or have friends scan the real QR from the lobby or TV screen.
5. Your friends select **JOIN A GAME** on their own phones. You need at least 3 contestants to start; 12 can actively play.
6. The host can open a TV screen or copy a private TV link. Turn on music/SFX only on the main TV to avoid echoes.
7. Start the match. Cards and voting remain private on individual phones.

**Important:** The 18+ toggle needs every player to confirm; spectator attacks are cosmetic. Your private GitHub repo and existing Render service are **not automatically updated** by a local ZIP. Use GitHub to deploy when ready.

**Changes:** Entirely new UI styling plus a TV clock-offset fix. All 42 avatar-related files and all avatar rendering functions are unchanged. Run `npm test` to verify.
